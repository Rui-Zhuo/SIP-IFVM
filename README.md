# SIP-IFVM post-processing

This repository contains post-processing, topology analysis, visualization,
and temporal tracking tools for SIP-IFVM simulations.

Run scripts from the repository root, for example:

```powershell
python classify_open_closed_field.py
python compute_lct_surface_velocity.py
```

The package layout, program responsibilities, terminology, and output naming
convention are documented in [docs/CODEMAP.md](docs/CODEMAP.md).
